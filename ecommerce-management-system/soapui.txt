================================================================================
           ECOMMERCE MICROSERVICES (V8) - SOAPUI REST TESTING GUIDE
================================================================================

This document contains step-by-step instructions to configure and test the 
v8 microservices architecture using SoapUI (or ReadyAPI / Postman).

--------------------------------------------------------------------------------
1. SERVICE & PORT MAPPING
--------------------------------------------------------------------------------
- API Gateway:      http://localhost:8080 (Single entry point & Consul router)
- Auth Service:     http://localhost:8083 (Dedicated Authentication Microservice)
- Product Service:  http://localhost:8081 (Products Microservice)
- Order Service:    http://localhost:8082 (Orders Microservice with Resilience)
- Consul UI:        http://localhost:8500 (Service Registry & Discovery)

--------------------------------------------------------------------------------
2. USER CREDENTIALS & JWT GENERATION
--------------------------------------------------------------------------------
You can generate tokens directly via Auth Service (8083) OR via Gateway (8080).

A. ADMIN USER:
   Direct URL:   POST http://localhost:8083/login
   Via Gateway:  POST http://localhost:8080/login
   Headers:      Content-Type: application/json
   Payload:
   {
     "username": "admin",
     "password": "admin123"
   }
   Expected Response (200 OK):
   {
     "token": "eyJhbGciOi...",
     "tokenType": "Bearer",
     "username": "admin",
     "role": "admin"
   }

B. NORMAL USER:
   Direct URL:   POST http://localhost:8083/login
   Via Gateway:  POST http://localhost:8080/login
   Headers:      Content-Type: application/json
   Payload:
   {
     "username": "user",
     "password": "user123"
   }
   Expected Response (200 OK):
   {
     "token": "eyJhbGciOi...",
     "tokenType": "Bearer",
     "username": "user",
     "role": "user"
   }

--------------------------------------------------------------------------------
3. SOAPUI PROJECT SETUP INSTRUCTIONS
--------------------------------------------------------------------------------
1. Open SoapUI.
2. Go to File -> New REST Project.
3. Enter URI: http://localhost:8080
4. For endpoints requiring authentication:
   - Select the request window.
   - Click the "Headers" tab in the bottom-left pane.
   - Click the '+' icon.
   - Header: Authorization
   - Value:  Bearer <COPIED_JWT_TOKEN>
5. For POST / PUT requests:
   - Header: Content-Type: application/json
   - Paste the payload into the lower request editor window.

SUITE F: SECURITY & RESILIENCE ERROR VALIDATION
================================================================================

Test F1: Missing Authorization Header
- Method:   GET
- URL:      http://localhost:8080/api/v1/orders
- Headers:  (Do not provide Authorization header)
- Expected: 401 Unauthorized
  {
    "error": "missing Bearer token"
  }

Test F2: Invalid / Expired Token
- Method:   GET
- URL:      http://localhost:8080/api/v1/orders
- Headers:  
    Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.invalid.signature
- Expected: 401 Unauthorized
  {
    "error": "invalid or expired token"
  }

Test F3: Invalid Order Status Transition
- Method:   PUT
- URL:      http://localhost:8080/api/v1/orders/1/status
- Headers:  
    Authorization: Bearer <ADMIN_JWT_TOKEN>
    Content-Type:  application/json
- Request Body:
  {
    "status": "SHIPPED"
  }
- Expected: 400 Bad Request
  {
    "error": "invalid status: must be CREATED, CONFIRMED, or CANCELLED"
  }

Test F4: Non-existent Order Lookup
- Method:   GET
- URL:      http://localhost:8080/api/v1/orders/999999
- Headers:  
    Authorization: Bearer <ADMIN_JWT_TOKEN>
- Expected: 404 Not Found
  {
    "error": "order not found"
  }

Test F5: Circuit Breaker & Resilience Verification
- Stop the Product Service (`localhost:8081`).
- Send 3 consecutive Create Order requests:
  POST http://localhost:8080/api/v1/orders
- Requests 1 and 2 will retry with exponential backoff (100ms, 200ms).
- Request 3 trips the circuit breaker to OPEN state.
- Expected: 502 Bad Gateway
  {
    "error": "product service unavailable or circuit open: resilience failure: circuit breaker is open"
  }
